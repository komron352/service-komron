# IMRAN SERVICE CRM

Системаи идоракунии хидматрасонӣ барои IMRAN SERVICE

## Насб
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
``` гарантия - strict:false, vite-env.d.ts мавҷуд

## Deploy Vercel
- Framework: Vite
- Build: npm run build
- Output: dist
